# Misinformation Cascade Tracker

## Graph-Based Propagation Analysis and Early-Risk Detection

### Project Overview

Misinformation can spread rapidly through interconnected social networks, making it difficult to understand how false information propagates and which users contribute significantly to its spread.

The Misinformation Cascade Tracker is a software-based system designed to identify misinformation and analyse its propagation using graph-based techniques.

The system represents users/posts as nodes and sharing, reposting or replying relationships as edges. It analyses cascade characteristics such as size, propagation speed, depth, growth rate and influential nodes.

### Objectives

- Identify misinformation using labelled data or machine-learning models.
- Construct propagation graphs for identified misinformation.
- Analyse cascade size, speed, depth and growth.
- Identify influential nodes involved in propagation.
- Develop an early-risk scoring mechanism.
- Visualize misinformation propagation patterns.

### Proposed Methodology

1. Data Collection
2. Data Pre-processing

4. Cascade Graph Construction
